# SHA-512

SHA-512 알고리즘을 이용한 해시값 생성 (Java)

```java
public class SHA512 {

    public static String createEncryption(String original, String hash) {
        String resultValue = String.format("%s%s", hash, original);
        String hex = null;
        try {
            MessageDigest messageDigest = MessageDigest.getInstance("SHA-512");
            messageDigest.update(resultValue.getBytes());
            hex = String.format("%128x", new BigInteger(1, messageDigest.digest()));
        } catch (NoSuchAlgorithmException noSuchAlgorithmException) {
            noSuchAlgorithmException.printStackTrace();
        }
        return hex;
    }
}
```
