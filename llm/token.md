# LLM과 토큰

AI 시대니까 LLM 정도는 간단한 거라도 직접 만들어보고 싶었다. 만들기 전에 LLM이 뭔지, 다들 말하는 "토큰"이 뭔지부터 봤다.

## LLM은 다음 토큰을 맞히는 프로그램이다

LLM(Large Language Model)이 하는 일은 하나다. 지금까지 나온 글을 보고 **다음에 올 조각 하나**를 맞힌다. 그걸 붙이고 또 다음 조각을 맞히고, 끝날 때까지 반복해서 답을 만든다.

```
"나는 밥을"          → 다음은? "먹었다"
"나는 밥을 먹었다"    → 다음은? "."
"나는 밥을 먹었다."   → 다음은? (끝)
```

다음 말을 잘 맞히려면 세상 지식이 필요하다. 그래서 다음 말 맞히기만 열심히 시켰는데 요약, 번역, 코딩까지 하게 된다.

할 수 없는 것도 있다.

- 그럴듯하게 틀린 말을 지어낸다 (환각)
- 학습한 이후의 일은 모른다
- 기억이 없다. 대화를 매번 통째로 다시 넣어준다
- 글만 쓸 수 있다. 실제로 뭘 하려면 도구를 연결해야 한다 → [MCP](../mcp/mcp-intro.md)

## 토큰은 모델이 한 번에 읽는 조각이다

처음엔 토큰이 단어를 쪼갠 거라고 생각했다. 거의 맞는데, 단어일 때도 있고 단어보다 작을 때도 있고 글자 하나일 때도 있다. 띄어쓰기, 마침표도 토큰이 된다.

```
"나는 밥을 먹었다"  →  나는 / ▁밥 / 을 / ▁먹 / 었다     (예시. 모델마다 다르다)
                               ▁ = 앞에 띄어쓰기 있음
```

답이 한 조각씩 끊어져 나오는 것도 모델이 토큰을 하나 만들 때마다 바로 보내주기 때문이다 (스트리밍).

## 토크나이저가 자주 붙어 다니는 조각을 합쳐서 만든다

토큰을 자르는 프로그램이 토크나이저다.

```
1. 글자 하나하나를 토큰으로 시작
2. 많은 글을 보면서 자주 붙어 다니는 조각을 하나로 합침
   "먹" + "었" → "먹었",  "먹었" + "다" → "먹었다"
3. 정해둔 개수가 찰 때까지 반복
```

문자 보낼 때 자주 쓰는 말을 단축키로 등록하는 거랑 비슷하다. 자주 쓰는 건 한 덩어리, 드문 건 잘게.

모델 입장에서 "단어"는 없고 토큰만 있다. 토큰 하나가 사전의 한 칸이고, 모델은 그 사전 안에서 다음 토큰 하나를 고른다.

## 학습을 많이 해도 토큰 수는 안 줄어든다

학습하면 토큰을 덜 쓰게 되는 줄 알았는데 아니다. 자르는 방식은 모델 학습 **전에** 정해지고 고정된다.

| 바뀌는 것 | 언제 |
|---|---|
| 자르는 방식 (토큰 수) | 토크나이저를 새로 만들 때만 |
| 맞히는 실력 | 모델을 학습할 때 |

사전에 단어를 몇 개 실을지는 인쇄할 때 정해진다. 그 사전으로 공부를 많이 한다고 단어 수가 바뀌진 않는다. 새 모델이 나오면서 토큰이 줄었다면 사전을 새로 찍은 거다.

## 한국어는 영어보다 잘게 쪼개진다

토크나이저가 영어 글을 훨씬 많이 보고 만들어져서 영어 쪽에 통째로 등록된 조각이 많다. 그래서 같은 내용이면 한국어가 토큰을 더 쓰는 편이다.

다만 최신 모델은 차이가 줄어드는 추세고, 이것 때문에 굳이 영어로 쓸 정도는 아니다. 영어로 대충 물어서 다시 물으면 오히려 더 쓴다.

## 사용량 제한의 토큰도 같은 토큰이다

하루 할당량, 요금, 길이 제한이 전부 이 토큰 단위로 센다. 내 질문 길이만 세는 게 아니라 모델이 **읽은 것과 쓴 것 전부**를 센다.

```
입력 토큰 (읽은 것)                       출력 토큰 (쓴 것)
  ├─ 지금 내 질문                           └─ 답변
  ├─ 앞에서 나눈 대화 전부   ← 계속 커짐
  ├─ 기본 설정 문구 (시스템 프롬프트)
  └─ 첨부 파일, 도구로 읽어온 내용
```

기억이 없어서 대화를 매번 통째로 넣으니까 대화가 길어질수록 질문 하나에 드는 토큰이 늘어난다.

```
1번째:  [질문1]
2번째:  [질문1 + 답1 + 질문2]
3번째:  [질문1 + 답1 + 질문2 + 답2 + 질문3]
```

그래서 주제가 바뀌면 새 대화로 시작하는 게 제일 쉽게 아끼는 방법이다.

## 직접 만들 땐 글자 하나를 토큰 하나로 쓴다

진짜 토크나이저는 만들기 번거롭다. 토큰을 크게 자르든 작게 자르든 모델 구조는 같으니까 구현할 땐 제일 쉬운 방법으로 간다.

```
"밥을 먹었다" → ['밥', '을', ' ', '먹', '었', '다']
```

구현 과정은 [LLM 직접 만들기](README.md)에 단계별로 적는다.
