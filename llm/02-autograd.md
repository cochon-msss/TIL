# 2단계: 경사는 컴퓨터가 구해준다 (backward)

[1단계](01-gradient-descent.md)에서 "많이 들어간 쪽이 많이 고친다"를 손으로 정했다. 신경망은 계산이 길어서 손으로 못 정하니까, 그걸 컴퓨터가 어떻게 해주나를 봤다.

처음엔 건드려보기, 영향 곱하기, 거꾸로 전달하기를 연달아 봤는데 하나도 이해 못 했다. "1단계에서 손으로 정한 걸 컴퓨터가 해준다" 한 문장으로 줄이니까 됐다. 2단계는 이게 전부다.

실습 코드: [code/02_autograd.py](code/02_autograd.py)

## 손으로 정하던 걸 backward()가 알려준다

1단계 영수증이다.

```
사과 2개 + 우유 1개 = 4000원
```

그때 "사과는 2개 들어갔으니 2만큼, 우유는 1개니까 1만큼 고친다"를 눈으로 보고 정했다. 이제는 계산식만 쓰고 컴퓨터한테 물어본다.

```python
apple = torch.tensor(500.0, requires_grad=True)   # "얘 영향 알고 싶어" 표시
milk  = torch.tensor(500.0, requires_grad=True)
total = 2*apple + 1*milk
total.backward()                                  # 누가 얼마나 영향 줬어?
apple.grad   # 2.0
milk.grad    # 1.0
```

| | 1단계 | 2단계 |
|---|---|---|
| "사과 2만큼, 우유 1만큼" | 내가 눈으로 보고 정함 | `backward()`가 알려줌 |
| 계산식이 길어지면 | 못 함 | 그래도 한 줄 |

`.grad`에 들어있는 게 1단계에서 말한 경사다.

## 1단계를 backward()로 다시 해도 똑같이 맞힌다

1단계 사과·우유 맞히기에서 "차이 × 개수"를 손으로 쓰던 줄만 `backward()`로 바꿨다. 고치는 건 그대로 `숫자 - 경사 × 0.02`다.

```
            1단계 (손으로)        2단계 (backward)
  1회:   사과  695, 우유  835    사과  695, 우유  835
 10회:   사과 1175, 우유 1800    사과 1175, 우유 1800
200회:   사과 1000, 우유 2000    사과 1000, 우유 2000
```

숫자가 한 자리도 안 다르다. 컴퓨터가 구한 경사가 손으로 정한 거랑 같다는 뜻이다.

## 속사정은 몰라도 된다

컴퓨터는 속에서 계산을 끝에서부터 거꾸로 따라가며 영향을 넘겨준다. 이걸 역전파(backpropagation)라고 부른다. 이름만 알아두고, 어떻게 하는지는 몰라도 LLM 만드는 데 문제없다. 앞으로 LLM 학습 코드는 이걸 계속 반복한다.

```
1. 계산해서 손실(벌점) 구하기
2. 손실.backward()            ← 경사는 컴퓨터가
3. 숫자 - 경사 × 학습률        ← 1단계에서 한 거
```
